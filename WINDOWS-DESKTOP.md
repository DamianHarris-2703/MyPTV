# Windows desktop build

**Build type:** Windows desktop application

MyPTV V3.0 Stable presents current and upcoming programmes, provider categories, favourites, followed competitions, sport, discovery suggestions, on-demand search, guide health and update history through the approved navy-and-mint top-navigation interface.

The production interface also distinguishes working channels without a matched schedule, repeatedly unavailable streams and channels still awaiting confirmation. Its UK and US schedule gaps remain the highest-priority enrichment queue; channels absent from a provider catalogue are intentionally irrelevant.

The public Windows build is a standalone portfolio simulation. It uses fictional records, requires no provider credentials and makes no network requests. The demo hub mirrors its principal navigation for visitors who prefer not to download an executable.
